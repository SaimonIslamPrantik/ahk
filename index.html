How to Run AutoHotkey Scripts

Follow these simple steps to run any AHK script on your Windows PC in seconds.

1

Install AutoHotkey

Download and install the official AutoHotkey runtime for Windows if you haven't already.

Official Website
2

Download Script

Click the Direct Download button on any script card above to get the .ahk file.

3

Double Click to Run

Double-click the downloaded .ahk file. Look for the green 'H' icon in your Windows tray!

Pro Tip: Want a script to start automatically with Windows? Press Win + R, type shell:startup, and place a shortcut to the script inside that folder.
